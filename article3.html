Disain Web Statis

Web statis adalah situs yang isinya tetap, tersimpan dalam file HTML, CSS, dan gambar, dan tidak membutuhkan database maupun pemrosesan di sisi server.

Karena tidak ada proses di server, web statis sangat cepat dibuka, aman, dan murah. Situs seperti ini cocok untuk portofolio, profil organisasi, dokumentasi, dan blog sederhana.

Web statis bisa dihosting gratis pada layanan seperti GitHub Pages. Cukup unggah seluruh file beserta foldernya, aktifkan fitur Pages, dan situs langsung bisa diakses lewat sebuah alamat.

Kekurangannya, setiap perubahan isi harus dilakukan dengan mengedit file secara manual. Untuk situs yang sering berubah, web dinamis dengan database lebih sesuai.
